# Caption controls: implementation and local QA

September 10, 2026 · Apple M5 Max · macOS 26.6.2 (25G83)

## Final owner direction

The toolbar stays centered at 260 × 44 pt. Size, color, and opacity replace its
contents; they do not expand its outline. Font selection remains a native menu
with each choice drawn in its typeface. Selecting a size or color restores the
four compact controls. Escape, clicking the captions, and outside dismissal
close the active control. Opacity has a native slider and a percentage.

The five text sizes are 10, 14, 18, 22, and 28 pt. The caption box stays 520 pt
wide, subject to the screen bounds. Its height stays fixed while changing text
size: 110 pt for system faces, with extra font-metric room for OpenDyslexic.
Actual glyph widths determine line breaks. A size or font change immediately
refills the two rows with recent text; subsequent speech preserves stable rows.
The preview uses a fixed, authored sample, never a saved user conversation.

Colors are White, Warm Yellow, Cyan, Mint, and Lavender. Only the current dot
appears in the compact bar. Background opacity ranges from 0–100% and does not
fade caption text. Reduce Transparency and Increase Contrast retain an opaque
background; Reduce Motion disables toolbar animations.

## Corrections made during QA

- Replaced approximate word capacity with actual font measurements.
- Fixed a row-boundary issue that could show fewer words after making text
  smaller. Appearance changes now fill from recent text and retain that origin
  as more speech arrives.
- Reflowed the current in-memory snapshot immediately, including during silence.
- Preserved historical width values for migration so an older 760 pt layout
  does not accidentally choose the largest new text size.
- Used the mouse event's window-to-screen position for local dismissal checks,
  avoiding reliance on a separately sampled cursor position.
- Switched opacity to NSSlider with explicit tracking and keyboard focus.
  External view updates do not reset its thumb during tracking.
- Made active controls take keyboard focus and release it when they close.
- Avoided publishing unchanged toolbar opacity on every hover timer tick.
