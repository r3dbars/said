# Said 0.1.1 Alpha

Caption controls now stay in one compact, centered bar. Choose a text size by
eye, switch fonts, pick a color, or adjust background opacity. Size, color, and
opacity each take over the same bar until you finish.

- Six fonts, including bundled OpenDyslexic. The font menu previews each face.
- Five text sizes from 10–28 pt. The caption box grows gently with the text;
  smaller type fits more words without leaving an oversized background.
- Proportional rounded corners, smooth resizing, and clearer hover feedback.
- Five text colors and background opacity from 0–100%. Text remains readable
  when the background fades, and appearance choices persist across launches.
- A system-audio capture fix for output devices that also expose an input,
  including the Display Audio route tested on this Mac. Unexpected audio-buffer
  layouts are rejected before reading sample data.

Download **Said-0.1.1-alpha.dmg**, open it, and drag Said into Applications.
Requires Apple silicon, macOS 26 or later, and English system audio. Allow
System Audio Recording Only on first launch. The pinned speech model downloads
once and is verified locally; it is not bundled in the installer.

The app and DMG are Developer ID signed, notarized, and stapled. This remains
an alpha: physical M1/16 GB performance, long-session testing, clean-machine
installation, and the model/conversion license review remain open. No model
weights are redistributed in this release.

Validation includes 67 deterministic tests, privacy checks, native UI inspection,
and signed-artifact verification. Live captioning was verified on the development
M5 Max using a public-domain fixture. The full interaction and hardware limits
are recorded in [UI QA](../UI-QA-2026-09-10.md) and the
[verification matrix](../reliability-matrix.md).

The GitHub release includes the exact source commit and SHA-256 checksum.
